# Repo Bloom

Build a whimsical interactive web app called “Repo Garden”.

For now, build only the frontend using mock repository data. Do not add authentication, database, GitHub API, or AI yet.

The experience:

- A magical developer garden where each GitHub repository becomes a plant, creature, building, or glowing object.

- Create a beautiful landing page with the headline “Grow your code garden”.

- Add a GitHub username input and a “Plant my repos” button.

- When clicked, show an animated garden scene using mock repository data.

- Display 6 projects as different magical objects.

- Add gentle animations, glowing effects, floating particles, paths, clouds, and hover interactions.

- Clicking a project should open a detailed side panel with project name, description, technologies, GitHub link, and an AI-style creative story.

- Add a “Garden Guide” chat button with mock responses.

- Add loading, empty, and error states.

- Make the design responsive for mobile.

- Use React, TypeScript, Tailwind CSS, and clean reusable components.

- Do not create a normal dashboard. The interface should feel playful, magical, polished, and portfolio-worthy.

- Use 2D CSS/SVG visuals only. Do not use complex 3D.
